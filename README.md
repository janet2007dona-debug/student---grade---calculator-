# student---grade---calculator-
A simple python program to calculate student grades 
Student Grade Calculator

About the Project

Student Grade Calculator is a beginner-friendly Python application that calculates a student's total marks, average percentage, and grade based on marks entered for different subjects.

Features

- Accepts student name and subject-wise marks
- Calculates total marks
- Calculates average percentage
- Automatically assigns a grade
- Validates marks between 0 and 100
- Handles invalid input
- Displays the final result clearly

Technologies Used

- Python
- Conditional Statements
- Functions
- Lists
- Loops
- Exception Handling

Grade Criteria

Average| Grade
90–100| A+
80–89| A
70–79| B
60–69| C
50–59| D
Below 50| F

How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run:

python grade_calculator.py

5. Enter the student's name and marks when prompted.

Learning Outcome

This project helped me understand Python functions, loops, lists, conditional statements, input validation, arithmetic operations, and exception handling.
